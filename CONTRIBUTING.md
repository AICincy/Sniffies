# Contributing to Sniffies

## Before opening a change

1. Read `AGENTS.md` and the relevant project documentation.
2. Keep each change focused and avoid unrelated formatting or binary updates.
3. Never add tokens, API keys, certificates, or local environment files.
4. Run the narrowest relevant validation and state the result in the pull request.

## Pull requests

Describe what changed, why it changed, how it was validated, and any follow-up work. Use the repository pull-request template.

## Binary artifacts

Do not replace or add Android packages unless the pull request states the source, version, checksum, and validation method. Large artifact strategy, releases, and distribution decisions require maintainer approval.
